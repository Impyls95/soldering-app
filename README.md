# Пайка с нуля

Адаптивное офлайн-приложение (PWA) для начинающих радиолюбителей: короткая теория, схемы, практика пайки и мини-тест.

## Как запустить

Приложению нужен HTTP-сервер: при открытии `index.html` через `file://` не работают Service Worker и установка PWA.

```powershell
cd "$env:USERPROFILE\Desktop\soldering-app"
python -m http.server 8000
```

Откройте <http://localhost:8000/>. Без сборки и зависимостей: только HTML, CSS и ванильный JavaScript.

> **Важно для телефона.** Service Worker и установка PWA работают только в защищённом контексте: на `localhost` или по HTTPS. Если открыть приложение по локальному IP вида `http://192.168.1.10:8000/`, уроки и картинки загрузятся, но офлайн-режим и установка будут недоступны. Для проверки на телефоне используйте HTTPS-туннель (например, `cloudflared tunnel --url http://localhost:8000`) или разместите папку на GitHub Pages / Netlify.

## Возможности

- Mobile-first вёрстка на CSS Grid и Flexbox, бургер-меню на телефоне.
- Светлая и тёмная тема; выбор сохраняется в `localStorage`.
- 14 разделов с отметкой «изучено», общим прогрессом и сохранением в `localStorage`.
- Мини-тест из 7 вопросов: автопроверка, разбор ошибок, лучший результат.
- Все уроки и изображения кэшируются Service Worker — тексты и схемы доступны офлайн.
- Web App Manifest и иконки: приложение устанавливается на телефон и ПК.
- Лайтбокс: нажмите на схему, чтобы рассмотреть её крупнее.

```
├── js/
│   ├── images.js           # конфигурация изображений

├── images/                 # фотографии, схемы, заглушка
└── icons/                  # иконки приложения и favicon
```

## Как заменить картинку

1. Положите новый файл в `images/` (например, `images/my-photo.jpg`).
2. Откройте `js/images.js` и найдите запись с нужным `id`.
3. Поменяйте `src`, `alt` и `caption`:

```js
{
  id: "soldering-iron",
  src: "images/my-photo.jpg",
  alt: "Краткое описание для незрячих",
  caption: "Подпись под картинкой"
}
```

В `index.html` картинка подключается только по `id`: `<div class="figure-slot" data-image="soldering-iron"></div>`. Менять разметку не нужно.

Если файл не найден или не загрузился, приложение автоматически покажет `images/placeholder.svg` — серую заглушку с подписью. Запись в конфиге при этом остаётся.

## Обновление PWA

После изменения файлов увеличьте `CACHE_VERSION` в `service-worker.js` (например, на `soldering-app-v1.1.1`). Пользователи увидят уведомление «Доступна новая версия» с кнопкой обновления. При первом запуске Service Worker активируется сразу.
